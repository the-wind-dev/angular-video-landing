# Выпускной проект LearnUp
Одностраничный лендинг с видео.

Основной реализованный функционал:
- Возможность оставить комментарий под видео;
- динамическая загрузка видео при скролле страницы.

Проект создан при помощи Angular CLI версии 13.2.6.
____
В проекте используется [динамичная загрузка компонентов](https://angular.io/guide/dynamic-component-loader#dynamic-component-loading), благодоря которой реализована ленивая загурзка блоков с видео и комментариев для видео. 
<br>Получение видео и комментариев происходит с фейковой базы данных (используется [json-server](https://www.npmjs.com/package/json-server)).
